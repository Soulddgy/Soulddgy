## About

세이프웨어에서 BLE/MQTT 기반 산업용 IoT 앱을 처음부터 끝까지 혼자 만들고 있습니다.  
기획 → 설계 → 개발 → 배포 → 운영, 전 과정을 직접 주도한 경험이 있습니다.  
모바일에 국한되지 않고 React 웹 대시보드, Node.js API, DB 설계까지 필요하면 합니다.

## Projects

### Safeware Connect
> 산업용 에어백 BLE 연결·모니터링 앱 | Flutter · BLE · MQTT · OTA DFU | 1인 기획·개발

분리 운영되던 두 앱을 하나로 통합 제안해 직접 개발. BLE 연결 모듈을 Stream 파이프라인으로 설계해 중복 구독을 차단하고, MQTT/REST API 역할을 분리해 트래픽 병목을 해소했습니다.

- Google Play · App Store 배포
- **BLE 제품군 매출 전년 대비 약 200% 성장 기여**

---

### REDY
> 노인 낙상 에어백 앱 + 보호자 모니터링 웹 | Flutter · React · BLE · MariaDB | 1인 기획·개발

앱과 관리자 웹 대시보드를 단독으로 기획·설계·개발·배포. 디자인팀·백엔드와 협업 회의를 직접 소집·리드했습니다.

- Google Play · App Store 배포
- 병원·요양기관 B2B 파일럿 운영 중

---

### Internal Tools
> 사내 테스트·운영 자동화 툴 | Flutter · C# · BLE · Google Drive API | 1인 개발

IMU 센서 데이터 수집 자동화, 다수 BLE 기기 동시 모니터링, 32비트 DLL 문제를 C# 파이프라인으로 해결한 IMU 6축 실시간 시각화 툴 등 개발.

- **데이터 수집 시간 10분 → 2분 (약 80% 절감)**
